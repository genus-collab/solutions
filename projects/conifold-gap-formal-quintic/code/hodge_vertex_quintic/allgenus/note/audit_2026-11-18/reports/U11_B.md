## Per-statement verdicts

### lem:mod-fixedx (s06_model_8.tex:7-14) -- verified
d_v p|_x = -(d_v x|_p)/(d_p x) = -(1/p)/((p^5-v)/p^2) = -p/(p^5-v). For omega = f dp written as f(p(x,v),v) p_x dx,
d_v|_x omega = (f_v + f_p pdot) dp + f d(pdot), pdot := d_v p|_x = -g, g := p/(p^5-v), and
Lie_{g d/dp}(f dp) = (g f_p + g' f) dp, so d_v|_x = d_v|_p - Lie_X in each variable. d_v(y dx)|_x = pdot dx = -dp/p.
int_{q in r} dp dq/(p-q)^2 = dp [1/(p-q)]_{q=0}^{infty} = -dp/p. All correct. (Implicit: the family is holomorphic
in v; true for all uses.)

### lem:mod-ibp (s06_model_8.tex:16-27) -- verified
(i) Lie_X(phi w) = d(iota_X(phi w)) (1-form on a curve), single-valued rational, so zero circle integral;
Lie_X(phi w) = (X phi) w + phi Lie_X w, X phi = (Xdphi)_+ + r/(p^5-v). r w/(p^5-v): no pole at 0 (w holomorphic
there), poles inside |p|=R, O(dp/p^3) at infinity => zero circle integral. Circle pairing of a polynomial = residue
pairing (w holomorphic at 0). Formula for phi = p^m: m p^m/(p^5-v) = m sum_j v^j p^{m-5-5j}, polynomial part as stated.
(ii) [iota_X w]_0^infty = 0 since g(0)=0, g = O(p^-4), w = O(dp/p^2). Correct. The hypothesis "zero residues" is not
used, and "holomorphic at 0, O(dp/p^2) at infinity" is implied by "poles only at the branch points" (harmless).
