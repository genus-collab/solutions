## Overall verdict

The unit is mathematically sound. Every proof in it was checked step by step and every
displayed formula on which an argument depends was re-derived by hand; the formulas that admit
an independent finite check were also checked by exact computation (see "Independent checks").
I found no fatal error, no gap and nothing that needs a repair to keep the downstream results
intact. The findings below are all minor: imprecise wording, compressed justifications that
close in a few lines, one mis-reference, one cross-reference to a step that proves a slightly
different (but equivalent by composition) statement, notation clashes, and one interpretive
caveat about the meaning of "the conifold expansion of F_g" (which the manuscript itself
acknowledges elsewhere).

Uses of the unit's statements downstream were checked against their hypotheses:
lem:set-dilaton (iii) in lem:flh-dil (kappa = d in 1+uQ[[u]], rings Q[[u]] and Q(zeta)((s))),
lem:set-dilaton (i),(ii) in lem:tra-conv (f) and lem:tra-F (genus-1 vertices have n >= 1),

## Findings (all minor)

### F1 (minor) The all-genus divisor equation in the statement of (T)
File sections/s02_setup_5.tex, line 42, label thm:set-GT.
Claim: "the classes Omega_{g,n} ... with Q = e^{T(q)} (which, by the divisor equation, is the
theory at the point t = T(q)H with Q = 1), equals R.omega".
Problem: the parenthetical uses the divisor equation for the higher-genus twisted classes
(and the vanishing of the degree-0 contributions of the H-insertions in all genera), while the
declared inputs only contain the genus-zero string/divisor equations ((G0), thm:set-G0 (b)).
The fact is standard (the twisting class e(R pi_* f^* O(5)) and the virtual class are compatible
with forgetting a point; degree-0 H-insertions are pullbacks and push forward to 0 when the base
is stable) and the logic does not need it if (T) is read exactly as quoted (for Omega with
Q = e^T). Repair: either state that (T) is quoted in the form "Omega_{g,n} at Q=e^{T(q)} equals
R.omega" (and delete "by the divisor equation"), or add the all-genus divisor equation of the
twisted theory to the list of quoted inputs.

### F2 (minor) Vanishing of the constant Conc(C_0, I_1) is justified tersely

Claim: "this constant vanishes, as its part of order q^0 involves only the leading coefficient of

antidiagonal J_{a,3-a}; with f-jet (1,0,0,0) and g-jet (l,1,0,0) the only candidate term is
f_0 J_{03} g_3 = 0. Also needed: the constants of D on Q[[q]][l] are Q (proved inside
lem:set-periods). Closes in two lines; add them.

### lem:set-pushins (s02_setup_5.tex l.3-38)
(i) PPZ (8): pi^*(psi_j^d) = psi_j^d - delta_j pi^*(psi_j^{d-1}). d=1: pi^* psi_j = psi_j - delta_j.
d=2: pi^*psi_j^2 = psi_j^2 - delta_j(psi_j - delta_j); comparing with (psi_j-delta_j)^2 gives
psi_j delta_j = 0 (rational coefficients). The transposition (j, N+1) preserves delta_j and swaps
psi_j, psi_{N+1}, so psi_{N+1} delta_j = 0 and psi_j psi_{N+1} = pi^*(psi_j) psi_{N+1}. Replacing
factors one at a time requires a factor psi_{N+1} to be present: c >= 1. Induction on m: LHS =
pi^*(X) psi_{n+m}^{c_m} by (*) at N = n+m-1 (all psi_i, i <= N, replaced), then (i) for m-1 and
(*) again with k_j = 0. Requires 2h-2+N > 0 at every step: true since 2h-2+n>0.
(ii) PPZ Def 2.5; projection formula; every term of Z_m carries psi_{n+s}^{c_s}, c_s >= 2,
so (i) applies; finiteness: 2m <= 3h-3+n+m. The last sentence is the definition of d^n Fbar
with q+z1 = ttr.
(iii) PPZ Defs 2.2, 2.13; gluing push-forward preserves integrals; finitely many relevant edge
monomials by dimension; vertex forms by (ii) with q_R + z1 = ttr_R (q_R = R^{-1}(z)(-z1) =
