## Detailed notes

### Re-derivation of the key identities

1. *Symplectic defect.* With S = Pc Psi^m and K = M D^{-1} M^{-1}: K(-z)^T = M(-z)^{-T} D(-z)^{-1} M(-z)^T = M(z) D(-z)^{-1} M(z)^{-1}; then R'(-z)^T eta^{-1} R'(z) = K(-z)^T [S(-z)^T eta^{-1} S(z)] K(z) = K(-z)^T K(z) = M(z)(D(-z)D(z))^{-1}M(z)^{-1}.
2. *Edge in lowered matrices.* For a lowered matrix X (colour -> H), the bivector (X^{-1}(psi) (x) X^{-1}(psi'))eta^{-1}_bivector equals X^{-1}(psi) eta X^{-1}(psi')^T; under X(-z)^T eta^{-1} X(z) = 1 it equals X(-psi)^T eta^{-1} X(-psi'), which is the form in rmk:flh-fail (iii) and cor:mai-gap.
3. *Hatting.* Lambda_s^{-1} eta Lambda_s^{-1} = eta and the abstract map Rhat'(zhat) = R'(s^4 zhat) (only the coordinates change) give Ntilde_{Rhat'}(psi,psi') = Ntilde_{R'}(s^4 psi, s^4 psi'); dividing by psi + psi' = s^{-4}(s^4 psi + s^4 psi') gives the factor s^4.
4. *Exponent count.* With V vertices, E edges: sum_v n_v = 2E, g = sum g_v + E - V + 1, so sum_v(3g_v-3+n_v) = 3g-3-E and sum_v(2g_v-2+n_v) = 2g-2. Then N = 4(3g-3-E+n_l) + 4E - 3n_l - (2g-2) - n_l = 10g-10.
5. *Unit of Psi_Q.* (Psi_Q)_{aj} = zeta^{j(a+1)} m_a, Delta_j^{-1/2} = zeta^j L/C_0; sum_j Delta_j^{-1/2}(Psi_Q)_{aj} = (L/C_0) m_a sum_j zeta^{j(a+2)} = 5 (L/C_0) m_3 delta_{a3} = 5 delta_{a3}, the lowered components of H^0.
6. *TFT = d.TFT^m.* Values: TFT at e~_i^n: (zeta^{4i} varpi_0 s)^{2g-2+n} (expanded); TFT^m: (zeta^{4i} vs)^{2g-2+n} with vs = s tau^{-1/4}; ratio d^{2g-2+n} with d = varpi_0 tau^{1/4}, which equals 1/p_{0,0} of lem:gau-diag. So the proof's abstract derivation agrees with the explicit values.
7. *Dilaton re-expansion.* lem:set-dilaton (iii): d^n F(q/kappa)[x] = sum_a kappa^{-a}/a! sum_b eps^b (N_a)_b / b! <x y^a> with N_a = 2h-2+n+a, = sum_a kappa^{-a} kappa^{N_a}/a! <x y^a> = kappa^{2h-2+n} d^n F(q)[x].
