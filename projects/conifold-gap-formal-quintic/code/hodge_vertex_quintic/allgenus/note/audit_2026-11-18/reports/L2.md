# L2 -- Literature audit: Eynard-Orantin, arXiv:math-ph/0702045 (v4)

Referee unit L2. Status: COMPLETE.

Verdict in one paragraph. Every statement of [EO] that the model section uses is quoted correctly, in the right
conventions, and is applied within its hypotheses. The model curve x = W_v(p) = p^4/4 + v/p, y = p on P^1 (v != 0) lies in
the class of [EO, Sections 3-4]. The sign dictionary (kernel, correlators, free energies) is right. The deformation
d/dv at fixed x is literally the "temperature" variation [EO (5-27)] between the two poles alpha = infinity,
alpha' = 0 of y dx. Equivalently, the path dOmega is the ray r from 0 to infinity with Lambda = -1, which is what the note
says. Independent checks: the base case (h,n) = (0,2) of the variational formula agrees analytically with EO's Rauch formula
(5-4). The cases (1,1) and (0,3) of thm:mod-var (i) hold numerically to 40 digits. No step of the model section needs
symplectic invariance, EO's homogeneity theorem or EO's dilaton theorem. Only minor points were found. The main one: the
proof of thm:mod-var (ii) uses [EO (5-15)], which the introduction declares to enter no proof. Part (ii) is not used
anywhere, and it also follows from prop:mod-period.

## 2. Item-by-item verdicts

### 2.1 Def. 4.2 (4-9) with the kernel (4-3): conventions and dictionary. VERIFIED (one trivial range caveat, finding m2)

EO's recursion (4-9):

    W_{k+1}^(g)(p, p_K) = Res_{q->a} [dE_q(p)/omega(q)] ( sum_{m=0}^g sum_{J in K} W_{|J|+1}^(m)(q,p_J) W_{k-|J|+1}^(g-m)(qbar,p_{K\J}) + W_{k+2}^(g-1)(q,qbar,p_K) ),

with W_1^(0) = 0 by (4-7), so the terms that contain W_1^(0) vanish. This is the manuscript's bracket, including the sum
Sigma' "with the two terms containing omega_{0,1} omitted". The EO kernel is

    dE_q(p)/omega(q) = 1/2 int_q^{qbar} B(.,p) / ((y(q) - y(qbar)) dx(q)),

whose integral runs from q to qbar. The manuscript's kernel integrates from iota_b q to q, and the denominator
(y(q) - y(iota q)) dx(q) is the same as EO's (4-1). So K_b = -K^EO, exactly as stated (s06_model.tex:20). The base data
agree: omega_{0,2} = B = W_2^(0), the Bergman kernel dp1 dp2/(p1-p2)^2 of P^1 [EO, Section 3, genus 0]; genus 0 has no
kappa, so EO's kappa-modified B is the plain one.

omega_{h,n} contains 2h-2+n kernels. The induction is on 2h-2+n: the term omega_{h-1,n+2} gives 2h-2+n kernels, plus 1;
a product gives (2h_1-2+|I_1|+1) + (2h_2-2+|I_2|+1) kernels, plus 1. Hence omega_{h,n} = (-1)^{2h-2+n} W_n^(h) =
(-1)^n W_n^(h) for 2h-2+n >= 0. Consistency check: omega_{0,3} = -W_3^(0) = -sum_b Res B B B/(dx dy) [EO (4-20)]. Direct
evaluation gives -sum_b e_{b,1} e_{b,1} e_{b,1} / x''(varsigma_b), which is lem:mod-genus0 (ii); I re-derived it from the
manuscript's kernel (bracket -2 e e dt^2, K ~ e/(2 x'' t dt)).

Caveat (finding m2): as printed, the dictionary omega_{h,n} = (-1)^n W_n^(h) carries no range. At (h,n) = (0,1) it is false,
since omega_{0,1} = y dx while W_1^(0) = 0 by (4-7). It is only ever used for 2h-2+n >= 0. A further triviality: the full
EO kernel also involves the vertex (4-1). That definition carries no sign difference, so citing (4-3) for the sign is correct.

### 2.2 Theorems 4.2 and 4.6, and EO's hypotheses on the curve. VERIFIED

What EO states:
- Thm 4.2: for (k,g) != (1,0), W_{k+1}^(g) has poles, in any of its variables, only at the branch points.
- Thm 4.6: W_k^(g) is symmetric.

The manuscript takes from them (s06_model.tex:24): for 2h-2+n > 0, omega_{h,n} is symmetric and meromorphic, with poles in
each variable only at the branch points, hence no diagonal poles. This is exactly the content of the two theorems, through
the (-1)^n dictionary. The range 2h-2+n > 0 excludes (0,1) and (0,2), and so stays inside EO's range.

EO's standing hypotheses [EO, Section 3, "We only require..."]:
1. a compact Riemann surface with meromorphic x, y, where E(x,y) is not factorizable;
2. all zeros of dx simple;
3. y behaving like a square root of x - x(a_i) near a branch point, i.e. y finite there with dy(a_i) != 0.

For the model curve, with v != 0:
- P^1 is compact, of genus 0.
- E(x,y) = y^5 - 4xy + 4v is irreducible: it is linear in x with coprime coefficients -4y and y^5 + 4v. The affine curve is
  even smooth, since E_x = -4y = 0 forces E = 4v != 0. And p -> (x,y) is injective.
- dx = (p^5 - v) dp / p^2 has exactly five simple zeros p^5 = v. At p = 0 it has a pole of order 2, and at p = infinity a
  pole of order 5 (in w = 1/p, dx = -w^{-5}(1 - v w^5) dw), so no zeros there.
- dy = dp != 0, and y is finite at the branch points.

conv:mod-kernel states hypotheses 2 and 3 (and compactness by working on P^1). It omits the non-factorizability, which holds
here. The pole structure needs no hypothesis in EO: x has a simple pole at 0 and a pole of order 4 at infinity, and y dx a
simple pole at 0 and a pole of order 6 at infinity. Consequences used downstream: holomorphy at p = 0 and p = infinity
(hence O(dp/p^2) at infinity) and the absence of diagonal poles. These are used in def:mod-pair, lem:mod-xfun,
lem:mod-abdks (step (2), clearing (p_i - p_j) and p_i), thm:mod-Lreg, lem:mod-ibp, the convergence of the ray integrals
in thm:mod-var and Fubini in prop:mod-V1. All of them are within the statement.

### 2.3 Def. 4.3 (4-10): free energies and the factor 1/(2-2g). VERIFIED

EO (4-10), for g > 1: F^(g) = (2-2g)^{-1} sum_i Res_{a_i} Phi W_1^(g), with dPhi = y dx and Phi an arbitrary antiderivative.
The manuscript (s06_model.tex:20), for h >= 2: (2-2h) FTR_h = sum_b Res Phi_{ydx} omega_{h,1}, with the same Phi and the
same factor. Since omega_{h,1} = -W_1^(h), FTR_h = -F^(h), as stated in s06_model.tex:21 and tab:sgn-tr row 22.

Here y dx = (p^4 - v/p) dp, so Phi = p^5/5 - v log p is multivalued. The branch choice at each branch point is harmless
because Res_{varsigma_b} omega_{h,1} = 0. The manuscript proves this itself (lem:mod-xfun with f = 1) rather than quoting
[EO (4-26)].

The definition is all that is used:
- cor:mod-trF uses only (2-2h) FTR_h = <Phi>^TR_h, thm:mod-tr, prop:mod-LD and the CohFT dilaton lemma. EO's dilaton
  Thm 4.7 is cited only as "cf.".
- prop:mod-period (iii) and thm:mod-gap use the definition, with the homogeneity proved directly in lem:mod-scale (ii)
  from the naturality of the recursion and the explicit scaling (i).

I re-checked lem:mod-scale (i): K -> K/(kappa mu), omega_{0,2} is unchanged, Phi -> kappa mu Phi, giving exponents
2-2h-n and 2-2h. EO's homogeneity Thm 5.3 is not used.

### 2.4 Theorem 5.1 (5-14) with (5-1), (5-4), (5-13) and Section 5.3 (5-27)-(5-30): thm:mod-var (i). VERIFIED

**(a) The deformation.** By lem:mod-fixedx, d_v p|_x = -p/(p^5 - v), so d_v(y dx)|_x = (d_v p|_x) dx = -dp/p. By
[EO (5-1)], delta_Omega y|_x dx = -Omega, which gives Omega = dp/p. A Bergman integral gives
int_{q=a}^{b} B(p,q) = dp (1/(p-b) - 1/(p-a)), so int_0^infinity B(.,q) = -dp/p, and Omega = int_r B(.,q) (-1). This is the
form (5-13) with dOmega = r (from 0 to infinity) and Lambda = -1, as the note says (s06_model_8.tex:39, b_signs_2.tex:24).

**(b) The type of deformation.** It is EO's temperature variation (5-27) with alpha = infinity, alpha' = 0. Indeed
int_infinity^0 B(.,q) = dp/p = Omega with Lambda = +1, and -dS_{infinity,0} = dp/p.

I checked (5-28) directly, although only the form (5-13) is needed:
- t_alpha = Res_alpha y dx: t_0 = -v and t_infinity = +v, so delta t_infinity = +1 and delta t_0 = -1.
- Filling fractions: none in genus 0.
- Potentials V_alpha, in EO's local parameters z_alpha = x^{1/d_alpha} [EO, Section 3.4]:
  - At infinity (d = 4, z = x^{1/4}): p = (4x)^{1/4} - v/(4x) + O(x^{-9/4}), so
    y dx = 4^{5/4} z^4 dz - v dz/z + O(z^{-6}) dz. Hence V_infinity = 4^{5/4} z^5/5, independent of v.
  - At 0 (d = 1, z = x): p = v/x + O(x^{-6}). Hence V_0 = 0.

So d_v|_x = d/dt_infinity - d/dt_0, which is (5-29), and (5-30) reads d_v W_k = int_infinity^0 W_{k+1} = -int_r W_{k+1}.

**(c) Hypotheses of Thm 5.1.**
1. Omega has the form (5-13). Its path avoids the branch points, so small residue circles can be taken disjoint from r,
   uniformly for v near v_0 (prop:mod-V1 chooses r so).
2. There is no hard edge (footnote 8).
3. The hypothesis stated just before (5-4) holds: Omega/dy = 1/p has no pole at the branch points.
4. Genus 0 has no kappa, so EO's covariant D_Omega = delta_Omega + tr(kappa delta tau kappa d/dkappa) equals delta_Omega.
   The note writes delta_Omega without saying this (finding m3).
5. The family stays in EO's class for all v != 0 (simple branch points, dy != 0, fixed pole profile of x).
6. The endpoints 0 and infinity of the path are poles of y dx, exactly as in EO's own (5-27). The W_{k+1} are holomorphic
   there by Thm 4.2, so the integrals converge.

Range: (5-14) requires g + k > 1; the manuscript's "n >= 1, h + n > 1" is the same condition. The meaning of the derivative
also agrees. "D_Omega W|_{x(p_i)}" is the variation of the coefficient of dx(p_1)...dx(p_n) at fixed x(p_i), and so is
the manuscript's d_v|_x. I re-derived the identity d_v|_x = d_v|_p - Lie_X of lem:mod-fixedx: for omega = f dp,
d_v|_x omega = (f_v + f_p p_v) dp + f d(p_v) with p_v = -X(p).

**(d) The sign translation.** d_v|_x omega_{h,n} = (-1)^n (-1) int_r W_{n+1} = (-1)^n (-1) (-1)^{n+1} int_r omega_{h,n+1}
= int_r omega_{h,n+1}. The factor is independent of (h,n).

**(e) Independent checks.**
- Analytic, (0,2): EO's Rauch formula (5-4) for Omega = dr/r gives
  sum_b Res_{r = varsigma_b} [r/(r^5 - v)] dr dp1 dp2 / ((r - p1)^2 (r - p2)^2) = sum_b (5 varsigma_b^3)^{-1} e_{b,1}(p1) e_{b,1}(p2).
  This equals the manuscript's direct computation lem:mod-genus0 (i), and by lem:mod-genus0 (iii) equals
  int_r omega_{0,3}. So the base case of EO's induction holds for this family, with the orientation and Lambda above.
  The (0,1) "base case" holds too: d_v(y dx)|_x = int_r omega_{0,2}(., q) (lem:mod-fixedx).
- Numerical, in the manuscript's convention: at v = 13/10, using the kernel of conv:mod-kernel with the local involution
  expanded to order t^10.
  - (h,n) = (1,1), p0 = 0.7 + 0.4i: d_v|_x omega_{1,1}(p0) = int_r omega_{1,2}(p0,q) holds to a difference of 5e-41.
  - (h,n) = (0,3), p = (0.7 + 0.4i, -0.3 + 0.9i, 0.2 - 1.2i): d_v|_x omega_{0,3} = int_r omega_{0,4} holds to a
    difference of 3e-41.
  - Side checks: Res_{varsigma_0} omega_{1,1} = 0, and int_r omega_{1,1} = -1/(12v), as in the proof of thm:mod-V (ii).

  Scripts: `audit/work/L2/var11.wl`, `audit/work/L2/var03.wl`. These are independent sanity checks of displayed
  formulas, not reruns of project code.

**(f) Use within hypotheses.** prop:mod-V1 applies thm:mod-var (i) with n = a + k >= 1 and 2h-2+n > 0. Then h + n > 1:
h = 0 forces n >= 3, and h >= 1 with n >= 1 gives h + n >= 2. All points lie off the branch points (circles of radius
R > |varsigma|, rays avoiding the branch points). The extra slot is integrated along the same kind of ray, with no diagonal
poles. The Lie terms are handled by lem:mod-ibp, which needs holomorphy at 0 and O(dp/p^2) at infinity, both from Thm 4.2.
Verdict: (5-14) is quoted correctly and applied within its hypotheses, and the deformation is of the type EO allow.

### 2.6 Symplectic invariance, homogeneity and the dilaton theorem: not needed. VERIFIED

[EO, Section 7, Thm 7.1] (symplectic invariance) is not cited, and no step of the model section needs it:
- The spectral curve is always (x, y) = (kappa W_v, mu p). DBOSS is applied to the superpotential with x = f(p) = 4 W_v,
  y = p, and ABDKS Thm 7.1 to (x = x(z), y = z): no x <-> y swap is made anywhere.
- The only change of curve is the rescaling (x, y) -> (kappa x, mu y) (thm:mod-tr step 2, lem:mod-scale). This is not a
  symplectic transformation (y dx scales by kappa mu), and it is handled by the explicit scaling law proved from the
  recursion.
- The pullback by m_k (lem:mod-scale (ii)) is an isomorphism of curves, under which the recursion is natural by definition.
- Hock's formula (rmk:mod-hock), from a paper on symplectic non-invariance, is explicitly not used.

This matters, since F^(g) invariance under x <-> y is known to fail in general for curves of this kind (cf. the title of
Hock25).

EO's Thm 5.3 (homogeneity) and Thm 4.7 (dilaton) are not used, as declared. Homogeneity is lem:mod-scale. The dilaton
identity enters only as the CohFT dilaton lemma (lem:set-dilaton) in cor:mod-trF.
