## 1. X3-4: eta^{-1} in the outer edge (def:set-outer s02_setup_8 l.46-48; thm:flh-main Step 1 s07_comparison_2 l.78)

Literal reading.
* def:set-outer declares R' to be "a series of maps from the colour space ... to H".
* N(psi,psi') = 1 - (R'^{-1}(psi) (x) R'^{-1}(psi')) eta^{-1} applies a tensor product of maps to eta^{-1}. So eta^{-1}
  must be an element of H (x) H.
* The same sentence calls 1 = sum e~_i (x) e~_i "the inverse bivector of the colour space". This parallel fixes eta^{-1}
  as the inverse bivector of (H, eta).
* That is how def:set-graphsum (s02_setup_4 l.72-75: "eta^{-1} in V (x) V is the inverse bivector") and def:flh-outer (iii)
  (s07_comparison l.31-33) define it.

So the literal reading is the bivector, and it is correct.

Matrices. Lowered components are Y = eta J, and the pairing on lowered components is the matrix eta^{-1} = eta/25. The
inverse bivector has lowered-component matrix eta eta^{-1} eta = eta. With A = [R'] (colour to lowered):
* N = 1 - A(psi)^{-1} eta A(psi')^{-T};
* for symplectic R', A(-z)^T eta^{-1} A(z) = 1, so A(psi)^{-1} = A(-psi)^T eta^{-1}, and N = 1 - A(-psi)^T eta^{-1} A(-psi').
  This is rmk:flh-fail (iii) and cor:mai-gap Step 2 (s10_main_2 l.27), where eta^{-1} is the pairing matrix, as it must be.

Every place in the chain where a matrix eta^{-1} appears uses it as the pairing on lowered components, which is correct:
* lem:flh-inputs (iii);
* lem:mai-Psi;
* cor:mai-gap Steps 1-2;
* cor:mai-natfact (c);
* def:tra-edge, which is in vector form, where the bivector does have matrix eta^{-1}.

What the chain uses of N:
* Step 1 uses only the degree property (coefficient of psi^a psi'^b through z^{a+b+1}), which holds in any reading.
* Step 2 uses E_{R''} = ((Psi^m)^{-1} (x) (Psi^m)^{-1}) E_{Pc}. This is exact in the bivector reading, because the
  isometry Psi^m maps the colour bivector 1 to the bivector eta^{-1}.
* cor:mai-gap uses E_{R'} = E_X. This is exact for the same reason, with Psi_cf, and needs no symplecticity.

The misreading. If eta^{-1} were taken as the matrix (1/5)delta in lowered components, then N(0,0) = 24/25 and the edge
would be E_true/25 (checked). That misreading is not what the text says, so the computations stand. Only the warning
belongs in the text. Classification: minor (wording).

## 3. U02-6: lem:set-dilaton (iii) for formal y (s02_setup_8 l.11-28)

Meaning of the left side. q/kappa + z1 = y/kappa + eps z1, with eps = 1 - kappa^{-1} in m (resp. in uQ[[u]]). Expanding
<x (y/kappa + eps z1)^m>, the y-degree-a part of the m-th term is (kappa^{-a}/(a! b!)) eps^b <x y^a (z1)^b> with b = m - a.
In <x y^a (z1)^b>_h:
* the psi-degree budget of the y-insertions is 3h-3+n+a-deg(x), independent of b, because each z1 insertion uses exactly
  the one unit of dimension it adds;
* so for fixed a the coefficient of each y-monomial is the single series sum_b (N)_b eps^b / b! <x y^a>, with
  N = 2h-2+n+a.
This series converges in R because eps is topologically nilpotent. So the sum over m converges coefficientwise in y. This
is what the proof means by "this holds coefficientwise in y". The value is (1-eps)^{-N} = kappa^N, and the identity
follows.

Checks of the hypotheses:
* (N)_b comes from b applications of (i), each needing 2h-2+(n+a+b') > 0, which holds since 2h-2+n > 0.
* The binomial series identity was checked exactly.
* In the n = 0 clause: for h = 0 the terms with a <= 2 vanish by the dilaton recursion down to M_{0,3} where psi = 0, and
  N = a-2 >= 1 otherwise.

Downstream uses.
* lem:flh-dil uses (iii) at the point kappa q with y = kappa q + z1 in z^2 V[[z]]. There a <= 3h-3+n-deg(x) (since
  k >= 2 for every y-insertion), so the double family is finite in a and convergent in b. In a complete non-archimedean
  ring it sums in any order, so substitution gives the Taylor expansion of def:flh-outer (ii).
* lem:tra-conv (f1) proves the same thing directly with explicit summability, and lem:tra-F uses only (f1).
* Over Q(zeta)((s)) the binomial series converges s-adically, since eps lies in s^5 Q[[s]].

Classification: minor (the statement should say how the left side is defined; the proof already does it).
