# Formal quintic: genus-2 conifold regularity check in the linear Hodge frame

## Context
For local P2 × C² and the resolved conifold × C², factoring the Givental–Teleman graph sum through a Hodge CohFT (frame B: R' = R·h_w^{-1}) made every stable graph with an edge regular at the conifold point, with the single-vertex graph carrying the whole pole. The user wants to see whether the same happens for the **formal quintic** of Lho–Pandharipande (arXiv:1702.06096 §0.2): T = (C*)^5 on P^4, twist by e(Rπ_* f^*O(5)) (Euler class in the numerator), weights λ_i = ζ^i λ (ζ^5 = 1), **no C² factor**. Quantum cohomology is semisimple, so Givental–Teleman reconstructs the higher genus from genus 0; the question is the behaviour at q_c = 5^{-5}, where L(q) = (1 − 5^5 q)^{-1/5} and all five eigenvalues ℓ_i = ζ^i λ L diverge together. Nothing in the repo or in the paper with Yannik touches the quintic; this is new code in a new folder.

**User decisions (2026-11-03).** LP18 ζ-specialisation; formal quintic alone (unrefined); linear Hodge frame Λ^∨_g(λ) with the **common weight λ** at every vertex (R' = R·h_{(λ)}^{-1}, h_{(λ)}(z) = exp(−Σ_k B_{2k}/(2k(2k−1)) z^{2k−1} λ^{1−2k}), exponent −1 as in FRAMEB_PROOF.md); regularity **per coloured graph after summing ψ-decorations**; **HKQ-style conifold frame** (substitute the conifold periods for the large-radius ones, as BS's Cf did for local P2), with the formal L-degree criterion reported as a by-product; Python exact arithmetic (own F_p with p ≡ 1 mod 5, Fractions where cheap); genus 2 first; no Mathematica. The user's standing rules apply (no TR/remodelling inputs; finite-order results are evidence; no edits to BS_v2 or to the proofs of record; agents never run wolframscript).

## Key facts from the design review (hand-derived; to be re-verified in code)
Conventions: H|_{p_i} = λ_i, e(T_{p_i}) = ∏_{j≠i}(λ_i−λ_j), O(5)|_{p_i} = 5λ_i; Λ^∨(w) = Σ(−1)^k λ_k w^{g−k}; Hodge_v = ∏_a Λ^∨(a)/a^g; h_v(z) = ∏_a Θ(−z/a); Hodge_v = h_v·1 (FRAMEB A3.2). Degree count: vdim M_g(P^4,d) = 5d+1−g = rank Rπ_*f^*O(5), so every N_{g,d} is a degree-0 function of λ; set λ = 1 in the code and keep λ only as the frame weight.
- **Pairing**: η(a,b) = Σ_i a_i b_i · 5λ_i/∏_{j≠i}(λ_i−λ_j); η(φ_i,φ_i) = 1/W_i^0 with W_i^0 = ∏_{j≠i}(λ_i−λ_j)/(5λ_i) = λ^3 ζ^{3i} at the ζ point.
- **Constant-map vertex at p_i** = (W_i^0)^{g−1} Hodge_{wt_i} with the 5-weight multiset wt_i = {λ_i − λ_j (j≠i), −5λ_i} (the numerator twist enters as −5λ_i via 1/Λ^∨(5λ_i) = (−1)^g Λ^∨(−5λ_i)/(5λ_i)^{2g}).
- **QRR constants** R|_{q=0} = diag(h_{wt_i}); the twist weight enters with a MINUS sign; h_{wt_i}(z) = h_{wt_0}(ζ^{−i}z), and h_{wt_0} has rational coefficients.
- **I-function at p_i**: I_i = z q^{λ_i/z} Σ_d q^d ∏_{k=1}^{5d}(5λ_i+kz)/∏_j∏_{k=1}^d(λ_i−λ_j+kz); I_i(q,z) = ζ^i I_0(q, ζ^{−i}z). Mirror theorem: Givental's equivariant P^n theorem plus Coates–Givental quantum Lefschetz for the convex twist (math/0110142 Thm 2, Cor 5.1). I = z C_0 + (C_0 H log q + a(q)1 + b(q)H) + O(1/z) with C_0 = I_0^Q = Σ(5d)!/(d!)^5 q^d, T = log q + b/C_0 (LP's mirror map), τ_0 ∝ e_1(λ) = 0 at the ζ point.
- **Picard–Fuchs**: [∏_j(M−λ_j) − q∏_{k=1}^5(5M+kz)] I = 0, M = zD, D = q d/dq; at the ζ point [M^5 − λ^5 − q(3125M^5+9375zM^4+10625z²M³+5625z³M²+1370z⁴M+120z⁵)] I = 0. Symbol: ℓ^5(1−5^5q) = λ^5, so ℓ_i = ζ^iλL, L = (1−5^5q)^{−1/5}, DL = (L^6−L)/5. Canonical coordinates u_i = ζ^iλ∫L dq/q stay finite and distinct; what degenerates is η(e_i,e_i).
- **Δ_i** = C_0² λ³ ζ^{3i} L^{−2} (from Y_3 = ⟨⟨H,H,H⟩⟩ = 5L^5/(C_0²C_1³), Y_0=Y_1=Y_2=0, Y_4 = 0 at the ζ point); Δ_i → 0 at q_c, unlike local P2. The expected pole of the vertex graph comes from the row/dilaton coefficients: ψ_{i,n}/ψ_{i,0} ~ L^{4n}, giving L^{10(g−1)} = t_c^{2−2g} with t_c ~ L^{−5}.
- **Local coordinate** s = 1/L (s^5 = 1−5^5q at λ = 1); the 5-fold cover is ramified at q_c, unramified at q = 0; L → ζL shifts the colour i → i+1.
- **Rows are not rational in L**: Dil_i(d) = (−1)^d[z^{d−1}](ψ_i/ψ_{i,0}) ∈ F_p(ζ)[L^{±1}] (if the WKB residues vanish, to be checked), but the H-rows carry C_0, C_1 = DT and D-derivatives (LP Thm 3 ring C[L^{±1}][A_2,A_4,A_6,C_0^{±1},C_1^{−1},K_2]). The cyclic basis v_k = H*^k (k = 0..4) is cleaner than the flat basis in rank 5: H*v_4 = (λL/C_1)^5 v_0, Gram matrix η(v_k,v_l) anti-diagonal (Y_3) plus the corner Y_8 = (λL/C_1)^5 Y_3; S(v_k) = ((z/C_1)D)^k[I/(zC_0)].
- **Differential ring**: generators ϖ_0 = C_0, ϖ_1 = C_0 T and their D-derivatives up to order 3 (PF reduces D^4), with 1/C_0 and 1/C_1 as tracked denominators; ONE quadratic (Griffiths/Wronskian) relation to derive and verify on q-series and to reduce by before any verdict.
- **Conifold frame Cf**: the differential-ring map (ϖ_0, ϖ_1) ↦ (ϖ_0^{cf}, ϖ_1^{cf}) where ϖ_0^{cf} (exponent 0, non-vanishing) and ϖ_1^{cf} = u + O(u²) (the vanishing period; t_c = ϖ_1^{cf}/ϖ_0^{cf}) are Frobenius solutions of the PF equation at u = 1−5^5q = 0 (exponents 0,1,1,2; rational series in u), fixed by the same pairing normalisation as the large-radius pair (⟨ϖ_0,ϖ_1⟩ = 0, derived in step 1; if the relation is not Cf-invariant, Cf is defined on a transcendence basis and this is recorded). After Cf every coloured graph term is an exact Laurent series in s.

## Open points to record in the write-up
- "Conifold point" here is not a discriminant zero: canonical coordinates stay finite, all colours become singular at once (η(e_i,e_i) → ∞); the mechanism of the P2 proof (one singular colour) does not transfer, so failure is possible and informative.
- The common weight λ is not one of the weights wt_i; the Z/5-covariant alternative h_{(λ_i)} is run as a comparison frame.
- Whether the formal quintic satisfies any conifold gap at all is itself unknown (same B-model ring as the true quintic, different ambiguity); the test reports the vertex graph's polar part regardless.
