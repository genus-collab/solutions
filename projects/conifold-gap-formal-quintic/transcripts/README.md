# AI transcripts

Where an AI system produced a substantial calculation, argument or proof
strategy, commit the transcript or reasoning trace here, where the tool's terms
permit. Name files `YYYY-MM-DD-<tool>-<topic>.md`.

## This project

The work was done in Claude Code sessions (November 2026). The raw session logs are not included: they are
very large, mix this project with others, and contain local machine paths. The record of what the AI agents
produced is kept in the project, next to the material it concerns, under `../code/hodge_vertex_quintic/`:
