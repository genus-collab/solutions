# Code

- **Language and version:** Mathematica 13.0 (`wolframscript`); Perl 5 with `Math::BigRat`; Python 3 (standard
  library, exact `fractions`); bash and SLURM for the genus-4 cluster run.
- **Dependencies / packages:** none beyond the above. The stable graphs are read from `StableGraph-<g>.bin`.
- **Folder layout.** This folder keeps the layout of the original working folder, so relative paths inside it
  work as they are:

  | item | what it is |
  |---|---|
  | `hodge_vertex_conifold/` | Hodge-vertex graph sum, genus 2–4 (`README.txt` there: conventions, results, files); mixed-scale vanishing (`proof_status_mixed_scale.md`, `conifold_regularity_note.md`); leaf structure (`leaf_proof/`); Lemma A (`lemmaA/`, status in `lemmaA/RESUME.md`); the CY torus and the rigidity proof (`cy_torus/`, `cy_torus_explore/`); genus-4 cluster results (`stanage_genus4/`) |
  | `cluster_genus4_hodge_conifold/` | genus-4 cluster package (SLURM scripts, `README.txt`) |
  | `resolvedconifold_genus3.nb`, `.m` | general-torus genus-3 notebook and its plain-text export; results in `resolvedconifold_results.m`, log `resolvedconifold_genus3_checks.log` |
  | `hodge_vertex_conifold/resolvedconifold_hodge.nb`, `.m` | runnable Hodge-vertex notebook and its plain-text export; it is generated by `make_hvc_notebook.wls` from `nb_hvc_*.m` |
  | `conifold_graphterms_genus2_3.m`, `conifold_CY_graphterms_polar.m` | per-graph conifold expressions and CY-torus polar parts, genus 2 and 3 (point vertices) |
  | `history/lp2_round6_patches/` | already-applied patch scripts of the local P² × C² work that edited documents of this project (do not rerun) |

  The LaTeX note that lived in `hodge_vertex_conifold/note/` is now `main.tex`, `sections/`, `main_summary.tex`
  and `summary/` at the top of the project; its working notes (outline, labels, notation) are in `../drafting/`.
  The `*.md` files are working notes, AI reports and referee reports; `*.out`, `*.log` and `*_out.txt` files
  are the stored outputs of the scripts.

- **Not included here:**
  - Mathematica `.mx` files (binary `DumpSave` caches, tied to the Mathematica version). They are rebuilt by
    `hvc_run.wls prep` (below), about 11 minutes for all twelve on one kernel. Checked on 2026-11-27: the
    rebuilt `hvc_factors_*.mx` and `hvc_orbits_*.mx` have definitions identical to the stored ones. The full
    genus-4 results `stanage_genus4/hvc_results_g4_Bm.mx` (219 MB) are rebuilt by `hvc_run.wls collect 4 B m`
    from the term files of the data release (`hvc_analysis.wls` and `hvc_summary.wls` read them when
    present). The `rc_samples_*.mx` of the genus-3
    notebook are rebuilt by the notebook with `recompute = True`; without it, the notebook reads
    `resolvedconifold_results.m`.
  - The 120 genus-4 term files `stanage_genus4/hvc_terms_g4_Bm_c<k>of120.m` and
    `hodge_vertex_conifold/lemmaA/E_formulas/engine_h5_r7.txt`: see `../data/README.md`.
  - Snapshot tarballs of the working folder.

- **To reproduce the main outputs** (from `hodge_vertex_conifold/`; genus 3 takes a few minutes per mode):

  ```
  wolframscript -file hvc_run.wls checks
  wolframscript -file hvc_run.wls g2sign
  wolframscript -file hvc_run.wls prep 3 B m
  wolframscript -file hvc_run.wls orbits 3 B m 1 2
  wolframscript -file hvc_run.wls orbits 3 B m 2 2
  wolframscript -file hvc_run.wls collect 3 B m
  wolframscript -file hvc_analysis.wls 3 Bm
  wolframscript -file hvc_summary.wls 3 Bm
  ```

  Modes: `A m`, `B m`, `point m`; genus 2 and 3. Rebuild the caches read by the check scripts with
  `prep 2 A m`, `prep 2 B m`, `prep 2 point m`, the same for genus 3, and `prep 4 B m` (about 11 minutes).
  Genus 4 needs a cluster: see `cluster_genus4_hodge_conifold/README.txt`; the assembled results are
  `hodge_vertex_conifold/stanage_genus4/hvc_results_g4_Bm.m` (without the per-graph terms, which are in the
  term files of the data release). The notebook `resolvedconifold_hodge.nb` runs headless with
  `wolframscript -file run_nb_headless.wls resolvedconifold_hodge.nb` (log `nb_headless_2026-11-27.out`).

Mathematica notebooks (`.nb`) are accompanied by a plain-text export (`.m`), so that changes are
diff-readable.
