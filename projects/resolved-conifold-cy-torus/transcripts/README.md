# AI transcripts

Where an AI system produced a substantial calculation, argument or proof
strategy, commit the transcript or reasoning trace here, where the tool's terms
permit. Name files `YYYY-MM-DD-<tool>-<topic>.md`.

## This project

The work was done in Claude Code sessions (September–November 2026). The raw session logs are not
included: they are very large, mix this project with others, and contain local machine paths. The
record of what the AI agents produced is kept in the project, next to the material it concerns:

| What | Where (under `../code/hodge_vertex_conifold/`) |
|---|---|
| Lemma A: briefs to the agents, reports of the five routes, referee reports, round syntheses | `lemmaA/brief.md`, `lemmaA/{A_mv,B_hurwitz,C_intersection,D_localization,E_formulas}/{report,referee}.md`, `lemmaA/round2/` (`brief.md`, `*/report.md`, `*/referee*.md`, `round2_status.md`), `lemmaA/round1_status.md`, `lemmaA/status_2026-10-31.md`, `lemmaA/RESUME.md` |
| Leaf structure (Theorem A): proof drafts and checks | `leaf_proof/` (`leaf_structure_proof*.md`, `S1`–`S4` notes and checks, `referee_scripts/`) |
| Mixed-scale vanishing: proof workflow, referee reports | `proof_status_mixed_scale.md`, `proof_M_{hurwitz,residue,framing}.md`, `referee_{hurwitz,residue}_1.md`, `mixed_scale_findings.md`, `review_checks/` |
| Rigidity (Theorem D) and the CY torus | `cy_torus/` (`RIGIDITY_PROOF.md` and scripts), `cy_torus_explore/` |
| Status notes of the regularity programme | `conifold_regularity_note.md` (and `*_before_round6.md`) |

Files named `*_before_round6.md` or `*_round5.md` are frozen earlier versions, kept as the record of what
the referees read.
