# AI transcripts

Where an AI system produced a substantial calculation, argument or proof
strategy, commit the transcript or reasoning trace here, where the tool's terms
permit. Name files `YYYY-MM-DD-<tool>-<topic>.md`.

## This project

The work was done in Claude Code sessions (September–November 2026). The raw session logs are not
included: they are very large, mix this project with others, and contain local machine paths. The
record of what the AI agents produced is kept in the project, next to the material it concerns, under
`../code/hodge_vertex/lp2_explore/`:

| What | Where |
|---|---|
| Plan and rulings of the all-genus programme | `ALLGENUS_PATHWAY_2026-11-01.md`, `RESULTS_2026-11-01.md` |
| Status and synthesis of each of the six proof rounds | `ROUND1_STATUS_2026-11-02.md` … `ROUND6_STATUS_2026-11-02.md`, `ROUND4_CRITICS_2026-11-02.md` |
| Proof drafts, in the versions the referees read | `FRAMEB_PROOF.md`, `ROUND2_PROOFS_rows_on_TF.md`, `ROUND3_PROOFS_H2_edges_PF.md`, `LP2_REGULARITY_PROOF_draft*.md` |
| Per-round agent reports, referee reports, scripts and outputs | `round1_scripts/` … `round6_scripts/` (one folder per task; `*_ref*` folders are the referees; `round5_result.json`, `round6*_result.json` are the workflow results) |
| LaTeX drafting reports | `../../drafting/latex_draft_report.json`, `latex_fidelity_report.json` |

Files named `*_round4.md`, `*_round5.md` or `*_round6a.md` are frozen earlier versions, kept as the record of
what the referees read.
