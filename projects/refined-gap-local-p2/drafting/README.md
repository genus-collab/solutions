# Drafting notes

Working notes of the LaTeX note (`../main.tex`), kept as they were when it was written: `OUTLINE.md` (plan of the
sections), `LABELS.md` (label scheme), `NOTATION.md` (macros and notation), `DRAFT_NOTES.md` (open drafting
points), and the reports of the drafting and fidelity passes (`latex_draft_report.json`,
`latex_fidelity_report.json`). `../summary/FIDELITY_CHECK.md` records the check of the abridged version against
the long one.
